# KMC Knowledge Assistant — Project Wiki

A retrieval-based assistant that matches a question to the closest row in the KMC knowledge base using TF-IDF vectors and cosine similarity. It is a retrieval system, not a generative LLM.

## Quick start

```bash
python -m venv .venv
pip install -r requirements.txt
python setup_model.py
python app.py
```
