# KMC Knowledge Assistant — Video Production Brief

**Target:** 45 seconds, 16:9, 1080p  
**Visual direction:** Editorial Swiss / architecture-inspired portfolio design: warm ivory canvas, high-contrast black serif titles, fine hairline rules, small vermilion monospaced labels, restrained grid layouts, compact project metadata. Use real repository screenshots and screen recordings; no generic robot imagery, fake dashboards, fabricated metrics or invented testimonials.

## Creative direction

A clean screen-recording-led walkthrough of a university knowledge-base assistant. Show the actual browser UI, a typed question, a matched answer, and a concise TF-IDF/cosine-similarity explanation. Do not portray it as an LLM or claim it can answer beyond its CSV knowledge base.

## Shot list

0–5s: ivory title card, “KMC KNOWLEDGE ASSISTANT”. 5–14s: show the real interface and sample question. 14–25s: show matched answer and explain retrieval. 25–35s: animate a simple TF-IDF → cosine similarity → answer flow. 35–45s: repo, Flask API and project title card.

## Voiceover draft

A focused retrieval assistant for navigating a curated knowledge base. It compares a question against prepared text and returns the closest matching answer.

## Production checklist

- Capture the current app from the repository; do not invent screens.
- Blur or exclude private data, credentials, tokens and personal information.
- Use only assets the repository owner has permission to publish.
- Verify any prediction, API response or feature shown in the edit.
- End with the repository name and a short GitHub URL.
- Export MP4 (H.264), 1920×1080, 24 or 30 fps, with readable captions.

## Generation prompt

Create a 45 seconds 16:9 1080p editorial software-project showcase for “KMC Knowledge Assistant”. Follow a warm ivory, black serif and vermilion monospaced Swiss portfolio aesthetic with precise grid alignment, thin rules, subtle transitions and clean screen-recording inserts. Use authentic project screenshots and the shot list above. Keep typography crisp and restrained. Do not fabricate UI, model outputs, performance metrics, users, testimonials or product capabilities. Avoid generic AI robots and neon sci-fi visuals. Finish on a quiet title card with the project name and GitHub repository.
